# My Bills

> What you spent this month, by day and by model.

## What this page does

Your bill is a table of days against model names. Three cards on top show this month total, call count, and the same period last month. The numbers come from real calls, not demo data.

## When you need it

- Check this month spend
- See which model costs the most
- Check whether one day looks unusually high

## What is on this page

| What you see | What it means |
| --- | --- |
| Select month / Refresh | Change the month and reload the data |
| Month total / Call count / Same period last month | Three headline numbers for comparison |
| Detail table | One row per day, one column per virtual model you used, plus a daily total and a month total; enterprise edition also shows a small token figure under each amount |

## Common tasks

**View a month**

1. Pick a month
2. Click Refresh
3. Read the three headline cards

**Check one day**

1. Find that row in the detail table
2. Read the daily total
3. Look across the row to see which model cost what

## If something goes wrong

**All amounts are zero**

Prices have not been configured for the vendor models yet; the page shows a notice. Calls are unaffected.

**No records this month**

You have not used the service yet, or data has not synced. Try a call and refresh.

## Still stuck?

Send the month and the amount (or the zero-price notice) to your administrator to check pricing.
