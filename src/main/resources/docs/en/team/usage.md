# Team Usage

> Company spend, who is using it, and which models cost the most.

## What this page does

This page is for operations staff and administrators. Switch between whole company and by department, choose a month, and read department summaries, a model ranking, and team / member tables. Figures come from real calls.

## When you need it

- Preparing a monthly AI spend report
- Finding the busiest department or person
- Seeing which virtual model is used most
- Checking which real vendor models sit behind a name

## What is on this page

| What you see | What it means |
| --- | --- |
| Whole company / By department + month | Set the scope and time period |
| Four summary cards | People, requests, usage and cost |
| Model ranking / usage type chart | Where most of the usage goes; enterprise edition shows cost and token volume side by side |
| Department usage / Member usage | Two levels of detail: people, requests, tokens, cost |
| Models behind a virtual model | Maps the employee-facing name to the real models, with tokens and cost per row |

## Common tasks

**Look at one department**

1. Switch to By department
2. Choose the department and month
3. Read the summary cards and member table

**Find the costliest model**

1. Read the model ranking
2. Cross-check the real models in the bottom table

## If something goes wrong

**Cost shows zero**

Prices are not configured for the vendor models yet. Add them in Providers → Model Management.

**No usage this month**

No calls in that scope and month, or data has not synced yet.

**Department list is empty**

Departments are not filled in on the accounts; complete them in Accounts first.

## Still stuck?

If numbers look wrong, send the month, scope and a screenshot to your administrator.
