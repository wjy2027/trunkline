# 常见问题

> 按你遇到的情况找，不用从头读。

## 连不上、报错

**工具提示「无效的密钥」或 401**

按顺序查三样：① 地址填的是**公司的接入地址**，不是厂商地址；② 密钥是从「我的密钥」复制的**完整密钥**，不是打码串；③ 密钥状态是「正常」，没过期、没被停用。还不行就看[快速上手](my/quickstart.md)和[全部密钥](team/all-keys.md)里的排查说明。

**提示「找不到模型」或 404**

你在工具里填了厂商原名（例如 gpt-4o），或者管理员删掉了那个虚拟模型名。到「我的额度」或「我的密钥」看一下**你能用的模型名**，改成它。管理员侧见[虚拟模型](team/model-pools.md)。

**提示「请求太频繁」或 429**

短时间内调用太多了，等一会儿再试。如果是常态，找管理员调整额度或限速。

**测试场能用，工具里不能用**

说明服务没问题，是工具那三栏没填对：地址、密钥、模型名。对照[快速上手](my/quickstart.md)逐项核对。

## 密钥

**完整密钥在哪里看**

到「我的密钥」，点那一行右边的复制图标。完整密钥只在创建时显示一次，别的地方复制到的都是打码串。

**密钥泄露了怎么办**

立刻联系管理员停用并重发。不要把它贴在群里、工单里或代码里。

**想申请一把新密钥**

「我的密钥」页点「+ 申请新密钥」，填用途后点「复制申请内容」，把这段现成的话发给管理员。系统里目前没有在线审批，不会自动提交。

## 金额和额度

**账单、团队用量里金额都是 ¥0**

管理员还没给厂商模型配单价。到「接入管理 → 模型管理」补上输入/输出单价后就会显示真实金额；这期间调用不受影响。

**额度设了却没拦住超量请求**

额度账本当前默认未启用，设了上限也不会真的拦截。需要管理员到「全局配置 → 额度怎么记」里启用。

**「申请更多额度」点了没反应**

该功能尚未接入在线审批，请直接联系管理员帮你调整。

**想按「每月最多花多少钱」来限制额度，设在哪**

企业版计费解锁后：给某把密钥设，在「全部密钥 → 配额」弹窗里填每月金额上限；给某个租户设，在「租户管理」的配额弹窗里。金额是按模型单价折算的估算视图，底层仍按 Token 记账；模型没配单价时金额栏填不了。

## 权限和菜单

**有些菜单我看不到**

菜单按角色显示：普通员工看「我的」，运维多看「团队」，管理员再看「系统」。看不到是正常的。

**菜单是灰的，点进去提示没权限**

这一项对你的角色可见但不可改（例如运维看「模型配置」「全局配置」）。需要改动时找管理员。

## 数据看起来不对

**刚用过的调用，观测页查不到**

先在「调用观测」把时间范围调对、状态切回「全部」，再点「查询」。仍查不到，把**调用编号（Trace ID）**和时间发给管理员。

**重启后状态对不上**

管理员可到「状态监控」点「立即同步」或「一键恢复」。单机部署通常不用管这一页。
