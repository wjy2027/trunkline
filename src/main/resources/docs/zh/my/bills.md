# 我的账单

> 按天、按模型，看自己这个月花了多少钱。

## 这个页面是干什么的

账单把每次调用的花费按「日期 × 模型名」摊成一张表。上面三张卡是本月总计、本月调用次数、上月同期，方便对比。数据来自真实调用记录，不是演示数字。

## 什么时候会用到

- 想知道这个月花了多少
- 想看钱主要花在哪个模型上
- 想对一下某一天是不是用多了

## 页面上有什么

| 你看到的东西 | 是什么意思 |
| --- | --- |
| 选择月份 / 刷新 | 切换月份、重新拉取数据 |
| 本月总计 / 本月调用次数 / 上月同期 | 三个总览数字，用来和上月比一比 |
| 消费明细 | 每一行是一天，每一列是一个你用过的虚拟模型；企业版每个格子里金额下面还带一行小字的 Token 用量，最后有「当日合计」和「本月合计」 |

## 常见操作

**看某个月**

1. 点「选择月份」，选月份
2. 点「刷新」
3. 看三张总览卡

**查某天花了多少**

1. 在明细表里找到那一行
2. 看「当日合计」
3. 想知道花在哪个模型上，看这一行各列的数字

## 遇到问题先看这里

**金额全是 ¥0**

管理员还没给厂商模型配单价，页面顶部会有提示。配好价格后就能看到真实金额，这期间调用不受影响。

**本月还没有调用记录**

这个月还没用过，或者数据还没同步；用一次之后回来刷新。

## 还是要人帮忙？

带上月份和你看到的金额（或 ¥0 提示），联系管理员核对价格配置。
