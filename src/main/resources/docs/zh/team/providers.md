# 接入管理

> 接新厂商、把模型加进来、配上价格。

## 这个页面是干什么的

公司要新增一家 AI 厂商，就在这里做。分「接入厂商」和「模型管理」两块：前者负责连上厂商并发现它有哪些模型，后者负责给模型配单价、额度、限速和熔断。

## 什么时候会用到

- 新增或替换一家 AI 厂商
- 厂商换了 API Key
- 给模型补单价（否则账单全是 ¥0）
- 某个模型要临时停用

## 页面上有什么

| 你看到的东西 | 是什么意思 |
| --- | --- |
| 第一次接 AI 服务？跟着向导走 | 四步引导：选厂商 → 填 API Key → 建虚拟模型 → 发密钥给员工 |
| 已接入的供应商 | 名称、地址、自动发现的模型数、状态（已连接 / 异常 / 未连接） |
| 添加供应商 | 选厂商预设、填名称和 API Key，再「保存并发现模型」 |
| 模型管理 | 模型名、上游厂商、状态、熔断 / 限流、输入 / 输出 / 缓存三档单价、计价、额度与限速 |

> 关于配额：模型这里的配额表单和「全部密钥」长一个样——主界面填**每月 Token 上限**，细粒度限制收在「高级限制（一般不用动）」折叠区里。
>
> 关于高级计价（企业版）：普通单价是「每百万 Token 多少钱」一刀切；高级计价可以给单个模型配**阶梯价**（一次调用输入越多，整笔单价越便宜）或**时段价**（按采购合同的峰谷价录入）。入口在模型管理里，总开关在「全局配置 → 其他」。

## 常见操作

**接一家新厂商**

1. 点「添加供应商」
2. 选厂商预设（国内 / 国外 / 本地）
3. 填名称和厂商的 API Key
4. 点「保存并发现模型」，勾选要用的模型
5. 点「接入选中的 N 个模型」

**补单价**

1. 切到「模型管理」
2. 找到模型，在「单价」列填输入 / 输出价格；若这家厂商对命中缓存的调用单独给优惠价，也可以填「缓存」一栏
3. 保存；之后账单和团队用量才会显示真实金额

> 说明：「缓存」单价是给命中缓存的便宜调用登记用的。目前账单仍按输入 / 输出价计算，缓存价会先保存下来，等系统开始统计缓存用量后自动生效——现在填了不会影响也不破坏现有金额。

**换 Key**

1. 在供应商列表点「查看模型」
2. 点「更换 Key」，填新 Key
3. 点「保存」

## 遇到问题先看这里

**员工说用不了刚接进来的模型**

光接进来还不够，必须先到「虚拟模型」页建一个员工用的名字并挂上这些模型，员工才能调用。

**提示「视频生成类网关暂不支持」**

这类厂商暂时无法自动发现模型，联系管理员手动处理。

**按钮是灰的，页面只能看**

你的账号只有查看权限；单价、额度、熔断、限流由管理员配置。

## 还是要人帮忙？

提供厂商名称、报错提示、以及你操作到哪一步。**不要把厂商 API Key 贴到工单或群里**，系统里也只保存、不回显。
