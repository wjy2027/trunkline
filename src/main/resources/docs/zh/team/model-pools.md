# 虚拟模型

> 员工用的模型名，背后可以挂多个厂商模型。

## 这个页面是干什么的

员工在 AI 工具里填的不是厂商原名，而是公司统一的「虚拟模型名」，比如 company-chat。这里决定这个名字背后挂了哪些真实模型、谁主谁备、怎么分摊流量，以及用量上限。**没有建虚拟模型，员工就没有能用的模型名**。

## 什么时候会用到

- 刚接完厂商，要给员工建一个能用的模型名
- 想给同一个名字加备用模型，主模型出问题时自动切换
- 想给某个名字设每分钟 / 每天 / 每月上限
- 想调整多个模型之间的分流方式

## 页面上有什么

| 你看到的东西 | 是什么意思 |
| --- | --- |
| 虚拟模型是什么？ | 页面顶部的说明卡 |
| 员工用的模型名 / 背后挂的模型 | 主、备标签与价格状态 |
| 策略 | 按权重随机、轮流使用、最少连接优先、按使用者固定、一致性哈希 |
| 价格状态 / 额度限制 / 状态 / 本月调用 | 是否配价、限额、启用状态与用量 |
| 新增虚拟模型 / 编辑 / 配额 / 删除 | 主要操作按钮 |

## 常见操作

**新建一个**

1. 点「新增虚拟模型」
2. 填名字，例如 company-chat
3. 点「添加模型」，勾选同分类的真实模型
4. 用上下箭头调主备顺序
5. 保存；员工就能用这个名字了

**加一个备用模型**

1. 点该行「编辑」
2. 添加另一个同分类模型，调整顺序
3. 保存

**设用量上限**

1. 点「配额」
2. 主界面填**每月 Token 上限**——大多数情况只填这一个就够
3. 每分钟 / 每小时 / 每日这些细粒度限制收在「高级限制（一般不用动）」折叠区里，一行两个，一般不用碰
4. 调告警阈值（用到百分之多少时提醒）
5. 点「保存额度」

## 遇到问题先看这里

**删除会怎样**

员工再用这个名字请求模型会直接报「找不到模型（404）」。删除前先确认没人还在用。

**提示「该模型分类下暂无实例」**

先到「接入管理」把厂商模型接进来。

**只能选同一分类的模型**

一个虚拟模型名不能混挂聊天和图像等不同分类的模型。

## 还是要人帮忙？

告诉管理员这个虚拟模型名、你希望挂哪些真实模型，以及期望的分流方式。
