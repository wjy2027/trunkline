# 全部密钥

> 全公司发出去的密钥，都在这里管。

## 这个页面是干什么的

运维和管理员在这一页给员工创建密钥、指定能用的虚拟模型、设每月额度，也能查某把密钥最近用得怎么样、停用或回收。上面四张卡是总密钥数、本月活跃、即将到期、发了没人用。

## 什么时候会用到

- 新员工要开通 AI，需要发一把密钥
- 员工说「用不了」，要排查
- 调整某人的每月额度
- 员工离职，回收密钥

## 页面上有什么

| 你看到的东西 | 是什么意思 |
| --- | --- |
| 创建密钥 | 填用途、持有人、可用虚拟模型、每月额度 |
| 描述 / 持有人 / 可用虚拟模型 / 每月额度 / 本月已用 / 到期时间 / 状态 | 列表主要列 |
| 排查 | 看这个人最近用得怎么样；页面会列出常见原因 |
| 配额 / 编辑 / 回收 / 更多 | 行内操作；回收＝停用，可随时重新启用 |
| 状态筛选 / 搜索 / 批量启用·停用·删除 | 快速定位一批密钥 |

## 常见操作

**发一把新密钥**

1. 点「创建密钥」
2. 填用途、选持有人、勾选可用虚拟模型、填每月额度
3. 保存
4. 让持有人到「我的密钥」查看并复制

**排查「用不了」**

1. 点该行「排查」
2. 看状态、额度、近 24 小时调用
3. 常见原因：填了厂商地址而不是网关地址、选的虚拟模型没勾选、密钥过期

**调额度**

1. 点「配额」
2. 主界面填**每月 Token 上限**；企业版还会显示**每月最多花多少钱（¥）**——这是按该密钥所用模型的单价折算出来的估算值，改动金额会自动换回 Token 上限保存
3. 更细的限制（每分钟 / 每小时 / 每日、按次数还是按 Token）都收在「高级限制（一般不用动）」折叠区里，一般只动月度值就够
4. 也可以在折叠区里「套用预设」，一键填一组常用组合
5. 点「保存配额」

> 额度设了却不拦截？额度账本要在「全局配置 → 额度怎么记」里启用后才会真的拦。

## 遇到问题先看这里

**提示「当前没有虚拟模型」**

先到「虚拟模型」页创建，否则发密钥时没有可选的模型。

**提示额度「不会真的拦截请求」**

额度账本当前未启用，设了上限也不会拦；需要真正拦截，要管理员在「全局配置 → 额度怎么记」里启用。

**回收和删除有什么区别**

回收只是停用，可随时重新启用；删除不可恢复，操作前请确认。

## 还是要人帮忙？

排查时把持有人账号、密钥「描述」、以及员工那边的报错原文一起带上。
