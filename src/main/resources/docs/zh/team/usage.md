# 团队用量

> 全公司花了多少、谁在用、钱花在哪个模型上。

## 这个页面是干什么的

这一页给运维和管理员看整体用量。可以切换「全公司 / 按部门」，选月份，看部门汇总、模型用量排行，以及部门、成员两级明细。数据来自真实调用记录。

## 什么时候会用到

- 月度汇报要统计 AI 花费
- 想知道哪个部门或哪个人用得最多
- 想看哪个虚拟模型最常被用
- 想核对某个名字背后实际用了哪些厂商模型

## 页面上有什么

| 你看到的东西 | 是什么意思 |
| --- | --- |
| 全公司 / 按部门 + 部门下拉 + 选择月份 | 切换统计范围和时间 |
| 四张总览卡 | 人数、请求数、用量、花费 |
| 虚拟模型用量排行 / 按用途类型分布 | 哪类模型用得最多，一眼看出大头在哪；企业版每个条目同时显示花费和 Token 用量 |
| 部门用量 / 成员用量 | 两级明细，列有人数、请求数、Token、花费 |
| 虚拟模型背后是哪些厂商模型 | 员工用的名字对应到实际调用的真实模型，每行带 Token 和花费 |

## 常见操作

**看某个部门**

1. 切到「按部门」
2. 选部门、选月份
3. 看汇总卡和成员表

**查花费最高的模型**

1. 看「虚拟模型用量排行」
2. 到最下面「虚拟模型背后是哪些厂商模型」核对真实模型

**导出或汇报前**

1. 先确认月份和范围（全公司 / 按部门）没选错
2. 再读三个总览数字

## 遇到问题先看这里

**花费显示 ¥0**

还没给厂商模型配单价。到「接入管理 → 模型管理」补上单价后即可看到真实金额。

**本月还没有用量**

该范围、该月份确实没有调用，或者数据尚未同步。

**部门下拉是空的**

账号上还没填部门。到「账号管理」把部门补齐，这里才能按部门汇总。

## 还是要人帮忙？

若数字明显对不上，把月份、统计范围和页面截图发给管理员核对。
