# 模型能力档案

> 看每个模型擅长什么，选型不再靠猜。仅运维和管理员可用。

## 这个页面是干什么的

接进来的厂商模型很多，到底哪个适合客服问答、哪个写代码强？这一页给每个模型一张「简历」：按用途、厂商、服务类型、能力强弱筛一筛，回答「该选哪个模型」。选好之后怎么配起来，用「虚拟模型」页建池，或用接入指南里的场景模板一键建。

## 什么时候会用到

- 要接新用途（比如做客服机器人），不知道挑哪个模型
- 想对比几个候选模型在代码 / 数学 / 推理上的强弱
- 想确认某家厂商有哪些服务类型（聊天 / 向量 / 重排等）

## 页面上有什么

| 你看到的东西 | 是什么意思 |
| --- | --- |
| 筛选器 | 按**用途**（客服问答、代码助手等）、厂商、服务类型、能力强弱、最慢延迟来筛 |
| 模型 / 标准型号 | 接入名，以及归一后的标准型号 |
| 强度 | 代码 / 中文 / 数学 / 推理四档评价 |
| 来源 | 这条简历是谁写的：**内置基线**＝系统自带、只收录公开可查的信息；不确定的会如实写「未知」，不会编造 |

## 常见操作

**为一个新用途挑模型**

1. 进入本页，用途选「客服问答」
2. 看筛选出的模型和四档强度，挑一两个候选
3. 到「虚拟模型」页把它们挂成一个名字给员工用

**对比候选模型**

1. 厂商选「全部」，服务类型选 chat
2. 对比几行的「强度」列
3. 拿不准就把候选都挂上池，用「团队用量」看实际表现再定

**想一键配好一组模型**

1. 到顶栏问号图标的「接入指南」，用里面的场景模板
2. 选一个用途，预览将创建的池和规则
3. 点「一键应用」，池名就是之后调用时用的 `model` 值

内置四个场景：客服问答（1 个聊天池 + 限流规则）、文档检索 RAG（聊天 / 向量 / 重排三个池）、代码助手（1 个聊天池 + 模型重写规则）、成本护栏（不建池，只出全局限流规则）。

## 遇到问题先看这里

**某项能力显示「未知」**

档案只写公开可查、有把握的信息，没把握的不猜。真实表现以你们自己的调用为准。

**价格为什么不在档案里**

价格随厂商频繁变动，这里写了很快就会过时；系统按每次调用的成交价记账，看「团队用量」和账单更准。

**筛出来的模型没接进来**

档案是全局参考数据，不代表已经接入。要先到「接入管理」把模型接进来、再到「虚拟模型」挂上，员工才用得上。

**一键应用后部分项被跳过**

某个服务类型还没有接入任何模型时，对应的池不会创建、依赖它的规则会跳过，避免落一条永远命中不了的配置；同名池已存在时也会跳过。看「注意 / 跳过项」的提示就知道跳了哪些。

## 还是要人帮忙？

选型拿不准时，把用途、预算范围和候选模型发给管理员一起看；真实用量数据在「团队用量」页。
