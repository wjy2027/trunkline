# 状态监控

> 数据存在哪、同步是否正常、出问题怎么恢复。

## 这个页面是干什么的

这一页实际是「数据存储」自检：网关运行时的状态（熔断保护、分流状态、用量额度等）存在哪里、哪台正在用、是否可用，以及同步和恢复操作。**单机部署通常不用管这页**。菜单叫「状态监控」，但这里不是实时故障大盘。企业版还会多一个「安全态势」子页签，把内容审核、敏感信息拦截这些安全动作的情况汇总成一张大盘，是给管理员看的安全总览，和存储无关。

## 什么时候会用到

- 多台网关一起跑，要确认大家用的是同一份共享存储
- 重启后状态对不上，需要同步或恢复
- 想看某种状态数据存了多少条

## 页面上有什么

| 你看到的东西 | 是什么意思 |
| --- | --- |
| 数据存在哪 | Redis 共享缓存 / 网关自带数据库 / 本机文件，三张卡标出「正在用」与「正常 / 不可用」 |
| 存了多少条 | 熔断保护、分流状态、用量额度、待同步的数量 |
| 管理操作 | 刷新、一键恢复、换个地方存、立即同步 |
| 明细列表 | 哪个服务、存的东西、运行状态、最后同步时间 |

## 常见操作

**日常检查**

1. 打开页面
2. 看三张存储卡哪台标「正在用」且状态「正常」

**手动同步**

1. 点「立即同步」
2. 看结果提示

**异常恢复**

1. 点「一键恢复」
2. 或在明细列表里找到对应行点「恢复」

## 遇到问题先看这里

**单机部署要不要配**

不用，页面顶部也写了「单机部署不用管这页」。

**点「换个地方存」提示已存在这里**

当前已经是目标存储，无需切换。

**提示「该状态类型不支持单独恢复」**

用「一键恢复」处理，或联系管理员。

## 还是要人帮忙？

改动存储位置前请先联系管理员；提供当前显示「正在用」的存储类型和异常提示。
