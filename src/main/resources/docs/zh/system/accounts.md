# 账号管理

> 谁能登录控制台、每个人是什么角色。

## 这个页面是干什么的

只有管理员能进这一页。这里创建员工账号、分配角色、填部门（部门用于「团队用量」按部门汇总），也可以停用账号或批量导入。部门的登记入口就在本页：编辑账号时部门只能从下拉里选，点「新增部门」先登记（登记后会生成一个稳定的部门编号，团队统计和按部门设额度都靠它）。企业版会多一个「组织」子页签，把部门管理做成完整页面，还能展示从公司通讯录（SCIM）同步过来的组织架构。

## 什么时候会用到

- 新员工入职要开账号
- 有人岗位变了，要改角色
- 有人离职，要停用账号
- 要按部门统计用量，先把部门补齐

## 页面上有什么

| 你看到的东西 | 是什么意思 |
| --- | --- |
| 总账户数 / 已启用 / 已禁用 / 管理员 | 四个统计数字 |
| 用户名 / 姓名 / 部门 / 角色 / 状态 / 创建时间 | 账户列表；角色有管理员、运维、用户、访客 |
| 创建账户 / 批量导入 / 刷新 / 搜索 | 常用操作 |
| 状态开关 | 一键停用 / 启用，不用删账号 |

## 常见操作

**新建一个账号**

1. 点「创建账户」
2. 填用户名、姓名、部门，选角色、设密码
3. 点「确定」

**停用某人**

1. 在列表里找到他
2. 拨「状态」开关，变为已禁用
3. 比删除安全，随时可恢复

**按部门统计之前**

1. 在账号编辑弹窗点「新增部门」，把部门先登记齐（企业版也可在「组织」子页签统一登记）
2. 再逐个把账号的「部门」从下拉里选好
3. 团队用量页才能按部门汇总，按部门设金额上限也要靠这些部门

## 遇到问题先看这里

**编辑时密码留空**

表示不修改密码，其他照常保存。

**删不掉默认管理员**

系统保护，默认管理员账号不可删除。

**角色怎么选**

用户＝只用自己的额度、密钥、测试场；运维＝还能管团队用量、接入、密钥、观测；管理员＝全部，含账号与系统设置。

**部门想手工敲一个名字**

不行，也不该这么做：部门必须先登记再选用，手工敲的自由文本不会生成稳定的部门编号，按部门统计和按部门设额度都认不了它。正确做法是先点「新增部门」。

## 还是要人帮忙？

账号问题联系管理员，提供用户名和你在页面上看到的提示。
