# 审计与版本

> 谁在什么时候改过什么；配置改坏了可以退回去。

## 这个页面是干什么的

只有管理员能进。两个基础页签：审计日志记录登录、密钥变更、认证失败、可疑活动等事件（含金额额度的调整记录）；配置版本保存每次配置变更，必要时可以把某个历史版本重新「应用」回去。企业版还会多三个子页签：**合规证据**（审计记录串成防篡改的链条，给合规检查用）、**合规归档**（审计记录锁定归档，谁也改不了）、**安全报告**（一段时间的安全情况汇总）。

## 什么时候会用到

- 要查谁在某个时间改了密钥或配置
- 有异常登录，想看认证失败记录并封禁来源
- 刚改完配置出问题，想退回上一版

## 页面上有什么

| 你看到的东西 | 是什么意思 |
| --- | --- |
| 审计日志 | 时间、用户、操作类型、涉及对象、客户端 IP、风险等级、结果、描述 |
| 常用筛选 | 全部 / 密钥变更 / 登录·权限失败 / 可疑与告警 |
| 导出 / 详情 / 黑名单 | 导出 CSV、Excel、JSON；可对来源封禁 IP 或封禁用户 |
| 配置版本 | 版本号、状态（当前版本 / 历史版本）、操作类型、操作详情、时间；可「查看」「应用」「删除」 |

## 常见操作

**查异常登录**

1. 切到「审计日志」，选「登录·权限失败」
2. 选时间范围，点「搜索」
3. 点「详情」；确认异常可点「黑名单」封禁 IP

**回滚配置**

1. 切到「配置版本」
2. 找到出事前那个版本，点「查看」核对
3. 点「应用」

**导出留档**

1. 筛选好条件
2. 点「导出」
3. 选 CSV / Excel / JSON

## 遇到问题先看这里

**删不掉当前版本**

只能删除历史版本，且删除后不可恢复。

**「应用」会发生什么**

把选中的历史版本设为当前配置，请先在「查看」里核对内容再操作。

## 还是要人帮忙？

涉及安全事件时，把时间、用户、客户端 IP 和风险等级一起提供给管理员。
