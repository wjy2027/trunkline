# 企业管理

> 企业版的「家底」入口：许可证、对账、安全防护、审批都从这里进。社区版菜单显示灰色锁。

## 这个页面是干什么的

把企业版才有的功能集中到一页，七个子页签各管一摊。菜单只在管理员角色下出现；社区版点开会提示升级企业版。每个子页签顶部都有一句话说明这页管什么。

## 什么时候会用到

- 换许可证、看授权还有哪些功能位
- 月底要和厂商账单对账，或查某笔花费归谁
- 要开敏感信息防泄漏、API 密钥加密保管、内容审核
- 想给密钥申请加一道审批
- 管理告警发到哪里（邮件、群机器人等）

## 页面上有什么

| 子页签 | 是什么意思 |
| --- | --- |
| 许可证 | 企业版的「授权书」：生效时间、包含哪些功能位（多租户、计费、安全等）。功能没解锁多数是这里没勾 |
| 对账与归因 | 把调用花费和账单对上号，看每笔钱归哪个租户/部门 |
| Agent 工具 | 给自动化程序（Agent）用的辅助能力入口 |
| 安全能力 | 三件事：**敏感信息防泄漏**（请求/响应里出现身份证号这类内容时拦截或打码）、**API 密钥加密保管**（厂商 Key 加密存放，不出现明文）、**内容审核**（按分数线拦截违规内容） |
| 告警通知 | 出事时往哪里通知：配接收渠道（如邮件、Webhook） |
| 密钥审批 | 开启后，员工申请密钥要经审批人才发 |
| 企业用量总览 | 多个租户一起跑时的用量大盘，跨租户汇总比较 |

## 常见操作

**检查为什么某个功能用不了**

1. 先到「许可证」页签看功能位是否包含
2. 功能位没问题再看具体页签里的开关是否开启
3. 例如模型管理里的「高级计价」灰着：先看许可证有没有计费位，再到「全局配置 → 其他」打开高级计价总开关

**开启敏感信息防泄漏**

1. 切到「安全能力」
2. 打开防泄漏开关，按需调整拦截分数线和例外模型
3. 保存后立即生效，先拿一条测试请求验证

**给密钥申请加审批**

1. 切到「密钥审批」
2. 开启审批流，指定审批人
3. 之后员工在「我的密钥」提交的申请会先到审批人这里

## 遇到问题先看这里

**整个菜单是灰的、点了提示升级**

当前部署没有企业版模块或许可证未生效；确认许可证文件已导入并在有效期内。

**安全能力拦截了不该拦的请求**

分数线设严了会「宁可错杀」。先在审计里看被拦记录的分数，再把分数线调松一点，或把该模型加入「不检查的模型」名单。

**告警没发出来**

先在「告警通知」里用测试按钮验证渠道通不通；再确认触发条件真的发生了。

## 还是要人帮忙？

涉及许可证的问题联系商务或供应商；安全拦截误判把**被拦内容的时间、模型、拦截原因**一起发给管理员。
