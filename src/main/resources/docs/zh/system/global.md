# 全局配置

> 全网关的统一默认设置；要单独调某个模型请去「模型管理」。

## 这个页面是干什么的

只有管理员能改。五个页签都用大白话命名：日志记多细、流量怎么分、模型连续出错怎么办、额度怎么记、其他。前四个改的是**所有模型的默认值**；某个模型要单独调，去「接入管理 → 模型管理」。「其他」放的是和单个模型无关的零散开关（高级计价总开关、隐私打码）。页头有「影响什么 / 何时该改」的说明，改之前先看一眼。

## 什么时候会用到

- 要统一规定请求内容记录到什么程度
- 要改默认的分流策略
- 要调整模型连续出错后暂时停用的阈值
- 要启用额度账本，让额度真正拦住超量请求
- 要开关高级计价，或开关日志里的隐私打码

## 页面上有什么

| 你看到的东西 | 是什么意思 |
| --- | --- |
| 日志记多细 | 仅元数据（不存内容）/ 摘要（脱敏后存前 N 字）/ 完整（加密保存，仅管理员可看） |
| 流量怎么分 | 全局默认策略，以及按模型类型分别设的「服务级配置」 |
| 模型连续出错怎么办 | 默认失败阈值、成功阈值、超时；高级项里还有自适应阈值和历史保留天数 |
| 额度怎么记 | 是否启用、账本后端、fail-open、落盘间隔；部分设置标注「需重启生效」且只读 |
| 其他 | ① 高级计价总开关（企业版）：开了之后才能在模型管理里配阶梯价等高级价格；② 隐私打码：把手机号、身份证号这类隐私信息在**存进调用记录前**替换成 `138****5678` 这样的样子，发给模型和用户的内容不受影响 |

## 常见操作

**改日志级别**

1. 切到「日志记多细」
2. 选一项，点「保存」
3. 涉及员工请求内容，建议先和合规要求确认

**改默认分流**

1. 切到「流量怎么分」
2. 在「全局默认配置」选策略，保存
3. 只想改某一类模型，就在「服务级配置」那一行点「配置」

**让额度真正生效**

1. 切到「额度怎么记」
2. 确认启用额度
3. 点「保存运行时配置」

**开关隐私打码**

1. 切到「其他」
2. 分别拨「请求记录脱敏」「响应记录脱敏」两个开关
3. 立即生效，不用重启；日志里新增的内容马上按新规则处理

## 遇到问题先看这里

**改了没生效**

部分项目标注「需重启」，页面上会明确写出来；这类要由管理员安排重启窗口。「其他」页签里的开关是即时生效的，不用重启。

**高级计价开关是灰的**

高级计价是企业版功能。纯社区版部署会显示灰色锁；企业版还需许可证包含计费能力，没包含时会有提示。

**想恢复出厂值**

在「模型连续出错怎么办」页签点「恢复默认」。

**运维点进来是灰的**

只有管理员能保存，运维的菜单项是置灰可见的。

## 还是要人帮忙？

改全局默认值会影响所有模型，建议先确认影响范围；拿不准时把五个页签的当前值截图发给管理员。
