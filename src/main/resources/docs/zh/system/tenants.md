# 租户管理

> 一套系统给多家公司（或多个独立团队）用，每家一个独立空间。企业版功能。

## 这个页面是干什么的

「租户」就是一个**独立空间**：里面的账号、密钥、虚拟模型、配置、账单，互相看不见、互不影响。适合集团给多家子公司分别用，或者给外部客户每家开一套。只有平台超级管理员能看到这个菜单。页面左边建租户、右边看列表，还能一键切换「我现在管理的是哪个租户」。

## 什么时候会用到

- 集团要给子公司 A、B 各开一个互不干扰的空间
- 给外部客户开独立空间，用完停用
- 要给某个租户设「这个月最多用多少」

## 页面上有什么

| 你看到的东西 | 是什么意思 |
| --- | --- |
| 创建租户 | 填一个英文标识（如 acme）和显示名称，创建后就有了一个独立空间 |
| 隔离提示 | 说明数据互相隔离；「当前租户」按钮用来切换你要管理哪一家 |
| 租户列表 | 标识、名称、创建时间；行内可「配额」和「停用」 |
| 配额弹窗 | 给这个租户设**每月 Token 上限**和**每月最多花多少钱（¥）**；更细的限制收在「高级限制（一般不用动）」折叠区 |

## 常见操作

**给子公司开一个空间**

1. 点创建卡片，填英文标识（创建后不能改）和显示名称
2. 点「创建」
3. 到「账号管理」给这家公司的员工开账号

**给租户设每月上限**

1. 在列表点「配额」
2. 填每月 Token 上限；企业版计费解锁后还可以填每月金额上限
3. 保存；超过上限的调用会被拦下并提示 429

**停用一个租户**

1. 在列表点「停用」
2. 这个空间里的账号就不能再用了；数据还在，不会删

## 遇到问题先看这里

**左上角显示的租户和我要改的对不上**

先在「当前租户」里点一下要管理的那家，再做后续操作——整个控制台的内容都跟着这个切换走。

**租户建错了**

标识创建后不能修改，只能停用后另建一个。停用不删数据。

**配额设了没拦住**

额度账本要在「全局配置 → 额度怎么记」里启用；金额上限还需要许可证包含计费能力。

## 还是要人帮忙？

租户属于平台级操作，误操作影响面大；拿不准时把租户标识和想做的事一起发给平台管理员确认。
