# 模型配置

> 厂商预设、模型分类、非标准接口的接入方式。

## 这个页面是干什么的

只有管理员能改这一页，运维看得到入口但没有权限（点开会提示没有权限）。基础页签三个：供应商模板（接入管理选厂商时用的预设）、模型分类、自定义接入协议。企业版还会多两个：**提示词模板**（把常用提示词存成模板，方便复用）和**适配器生命周期**（接入协议的上线下线管理）。多数情况不需要动这里 —— 接新厂商时系统会自动选好接入方式。

## 什么时候会用到

- 想检查哪些厂商预设地址还可用
- 要新增或调整模型分类
- 某家厂商接口不标准，需要手动加一种接入协议

## 页面上有什么

| 你看到的东西 | 是什么意思 |
| --- | --- |
| 供应商模板 | 名称、模板 ID、分类、类型、接口地址、常用模型、可用性；可「检测可用性」「一键隐藏不可用」 |
| 模型分类 | 分类名、接入方式、分流策略、用量上限、故障自动停用；不填就用全局配置的默认值 |
| 自定义接入协议 | 名称、接口风格、类型、能力；可「测试连接」验证 |

## 常见操作

**清理不可用的预设**

1. 切到「供应商模板」
2. 点「检测可用性」
3. 点「一键隐藏不可用」

**加一种非标准接入方式**

1. 切到「自定义接入协议」
2. 点「添加适配器」，从模板创建或自定义
3. 填地址和 Key
4. 点「测试连接」，成功后保存

## 遇到问题先看这里

**内置预设改不了**

内置模板是系统自带的，不可修改；需要变化就新建一个自定义模板。

**点「测试连接」失败**

先核对地址和 Key。注意这里填的是厂商侧信息，不是员工用的网关地址。

**运维点进去是灰的**

只有管理员能改这一页，这是有意设计的权限限制。

## 还是要人帮忙？

提供厂商名称、接口风格和「测试连接」的失败提示；同样不要贴厂商 API Key。
